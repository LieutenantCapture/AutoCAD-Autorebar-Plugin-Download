## 🧠 Overview

AutoRebar is a specialized reinforcement detailing add-on for Autodesk AutoCAD, designed to support the preparation of reinforced concrete drawings. It introduces dedicated tools for creating, editing, and organizing reinforcement elements directly within the CAD environment.

The software provides intelligent objects for reinforcing bars, crosshairs, marks, callouts, and other detailing components. These objects can be linked together, helping keep reinforcement geometry and associated drawing information synchronized as a project changes.

AutoRebar simplifies common drafting operations such as defining bar shapes, adjusting diameters, specifying spacing, and organizing reinforcement marks. Its tools can support detailing work for concrete structures including slabs, walls, columns, and foundations.

The add-on also includes automated Bar Bending Schedule (BBS) generation and quantity-related features. Schedules can be inserted into drawings or exported for further processing, helping streamline reinforcement documentation and reduce repetitive drafting work.

## Additional Information for Windows Users

AutoRebar is intended for reinforcement detailing workflows involving reinforced concrete structures. Its specialized objects allow users to create and modify bars, configure spacing, add marks, and organize drawing information within AutoCAD.

The software maintains relationships between reinforcement elements and related annotations. When linked geometry or parameters are changed, associated data can update automatically, helping maintain consistency throughout the drawing.

Bar Bending Schedules can be generated for an entire drawing or for selected areas. Depending on the workflow, schedules may be placed directly in the drawing or exported to Excel for further review and documentation.

AutoRebar includes configurable settings for units, mark formats, terminology, and schedule layouts. These options can help adapt the drawing workflow to different project conventions and documentation requirements.

Before installation, check that your AutoCAD version is supported by the AutoRebar release you intend to use. For large or detailed reinforcement drawings, additional system memory and processing resources may improve responsiveness.
